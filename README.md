# InkluMap

InkluMap adalah sistem pemetaan kebutuhan akomodasi pembelajaran berbasis data mining untuk membantu sekolah inklusif mengidentifikasi kebutuhan siswa, menyusun rekomendasi akomodasi, dan menentukan prioritas layanan.

## Teknologi

- Next.js dan React
- FastAPI
- PostgreSQL
- Python
- Hierarchical Agglomerative Clustering
- Gower Distance
- DBSCAN
- Plotly atau ECharts

## Fitur Utama

- Pengelolaan data siswa
- Asesmen kebutuhan fungsional
- Pemetaan kelompok kebutuhan
- Rekomendasi akomodasi
- Deteksi kasus unik
- Prioritas anggaran
- Monitoring tindak lanjut
- Ekspor laporan PDF dan Excel
